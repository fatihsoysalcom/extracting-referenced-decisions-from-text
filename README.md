# Extracting Referenced Decisions from Text

This example demonstrates how to programmatically extract specific "decisions" along with their "justifications" and "verifiable references" from a block of text. It simulates the core concept of moving beyond simple information retrieval to structured decision recovery, as discussed in the article. The Python script uses regular expressions to identify and link these key pieces of information, showcasing how context and source attribution can be programmatically achieved.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run it from your terminal using `python main.py`.
